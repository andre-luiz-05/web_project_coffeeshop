# Triple Espresso

## Descrição
Página web para a cafeteria Triple Peaks Library, desenvolvida com HTML e CSS.
O site apresenta informações sobre o café, receitas em vídeo, formulário de
reserva de mesa e rodapé com links para redes sociais.

Tecnologias utilizadas: HTML5, CSS3 (metodologia BEM).

## Planos de melhoria
- adicionar melhorias para dispositivos móveis
- implementar o formulário com javascript
